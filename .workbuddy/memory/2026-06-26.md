## AGENTS.md 新增人机协作创作工作流

在 AGENTS.md 中新增了「人机协作创作工作流」章节，位于「验证 abbrlink 一致性」和「部署到生产环境」之间。

**工作流四阶段：**
1. 人提供思路 → AI 生成标题 + `hexo new`（不写正文）
2. 人编写核心内容，用 `<!-- AI填充 -->...<!-- /AI填充 -->` 标记预留段落
3. AI 填充预留段落 → 格式规整 → 生成 tags → 生成标题图 → 构建验证 → 部署
4. （可选）英文翻译，重复上述流程

**关键设计：**
- AI 第一阶段只建文章壳，不写正文——人控制核心内容
- `<!-- AI填充 -->` 标记支持带指令形式（如字数约束）
- 英文站 tag 用连字符，中文站 tag 用空格分隔
- 汇总流程图清晰展示了人机分工边界
