## 它能做什么

先说结论：给它一段文字描述，它还你一条完整的视频。

具体来说，有三种玩法：

**简单视频**——给一句描述，直接生成一段5到20秒的AI视频。支持文生视频、图生视频、关键帧模式，分辨率可以选竖屏9:16、横屏16:9或者方形1:1。适合快速出个短片试试效果。

**创意视频**——这才是重头戏。你只需要写一个故事创意，比如"暗黑版青蛙王子童话"，AI会自动帮你完成这些：把创意扩展成完整故事、提取角色描述并生成角色参考图、把故事拆分成多个场景并为每个场景写详细的视觉提示（镜头语言、光影、色调那种）、生成每个场景的AI视频、写旁白文案并用TTS配音、自动生成逐词对齐的字幕、最后把所有场景拼接成一条完整视频。整个过程全自动，10个步骤一气呵成。

**文稿视频**——适合做知识类、解说类内容。你贴一篇长文章或者脚本进去，系统会按语音时长自动分段（大约每秒4个字），每段生成对应的AI视频画面，再用统一的TTS旁白和字幕把整段内容串起来。贴篇博客文章进去，出来就是一条解说视频。

## 配音和字幕：比想象中好用

配音这块值得单独说一下。Edge TTS 提供了4个中文音色：温柔女声（晓晓）、沉稳男声（云扬）、活泼女声（晓伊）、青年男声（云希）。语速可以在-30%到+30%之间调节。

字幕不是简单地把旁白文本切几段糊上去，而是利用 Edge TTS 的 SubMaker 拿到了**逐词级别的时间戳**，每2到3个字就有一条字幕，和语音的同步非常精准。长字幕还会自动换行，换行点会优先选在标点符号处，不会出现一个字被挤到第二行的尴尬情况。

字幕的样式也完全可以自定义：字体、颜色、大小、位置（顶部或底部）、描边、半透明背景，都可以调。

## 场景之间怎么衔接

多场景视频最头疼的就是场景之间的衔接。一个故事拆成5个场景，如果每个场景都是独立的，拼在一起就会很跳。

这个项目提供了三种衔接模式：

**关键帧模式（推荐）**——给每个场景指定首帧和尾帧图片。场景N的尾帧自动成为场景N+1的首帧，这样相邻场景在视觉上就能连贯起来。效果最平滑。

**过渡帧模式（ti2vid）**——提取上一个场景的最后一帧，用img2img生成一张过渡图，作为下一个场景的起始帧。也能实现连续感，但控制精度不如关键帧。

**独立模式**——所有场景用同一张参考图独立生成，彼此不关联。适合不需要强连续性的内容，比如解说视频。

## 技术架构简单聊

后端是 Python + FastAPI，前端是一个单文件HTML SPA（Tailwind CSS，零构建步骤），整个项目5000多行Python加1500行前端代码，结构很清晰。

几个我觉得做得还不错的设计：

**断点续传**——每完成一个pipeline步骤，状态会原子写入 `task_state.json`（先写临时文件再 `os.replace`，防止进程被杀导致文件损坏）。服务中断后重启，找到未完成的任务点"继续"就行，已完成的步骤不会重复调API。

**统一的音频轨道**——不是给每个场景单独配音再拼接（那样会累积空白间隙），而是先把所有场景视频拼起来，再在整条时间轴上叠加一整条旁白+字幕。如果旁白比视频长，还会自动把最后一帧冻结延长。

**CJK字体回退**——渲染字幕时会自动检测字体是否支持中文，如果选了一个不支持CJK的字体（比如Arial），会自动回退到内置的黑体，不会出现中文字符显示成方框的问题。

**WebSocket实时进度**——生成过程中前端会实时显示每个步骤的状态，不用干瞪眼等。

## 怎么用

三步搞定：

```bash
# 1. 克隆并启动
git clone https://github.com/easyeye163/agnes-video-generator.git
cd agnes-video-generator
./start.sh

# 2. 获取免费API Key
# 访问 https://platform.agnes-ai.com 注册获取

# 3. 打开浏览器访问 http://localhost:8765，填入API Key，选模式，写创意，点生成
```

`start.sh` 会自动创建虚拟环境、安装依赖、启动服务。环境要求就两个：Python 3.10+ 和 ffmpeg。

如果你用AI编程助手（Cursor、Claude之类的），这个项目还专门准备了 `AGENTS.md`，直接让Agent读这个文件就能自动完成部署和验证。

## 一些已知局限

老实说，这个项目还在早期阶段，有些边角情况没处理得特别完美：

网络不稳定时某些步骤可能会重试失败；长视频（超过20秒的单场景）生成时间会比较长，需要耐心；自定义尾帧数量如果不匹配场景数，行为是未定义的；并发生成多个视频任务可能会有资源竞争。

但核心的生成流程是稳定的，我自己用下来没什么大问题。
