Nearly every AI video tool on the market charges you by the second. Generate a fifteen-second clip and a few bucks are gone. Try making a proper short film and it really starts to sting.

After tinkering with a few of these tools, I decided to build my own — [Agnes Video Generator](https://github.com/easyeye163/agnes-video-generator), a **completely free AI video generator**. Not a free trial, not a limited tier, not a stripped-down version. The entire pipeline — script writing, image synthesis, video rendering, voiceover, and subtitles — runs at absolutely zero cost.

All you need is a free API key from [Agnes AI](https://platform.agnes-ai.com), and you can generate narrated, subtitled, multi-scene AI videos without spending a cent.

## What It Can Do

The short version: give it a text prompt, get back a finished video.

There are three modes:

**Simple Video** — Describe a scene, get a 5-to-20-second AI video clip. Supports text-to-video, image-to-video, and keyframes mode. Pick portrait 9:16, landscape 16:9, or square 1:1. Great for quick experiments.

**Creative Video** — This is the main event. You write a story idea — say, "a dark-twist version of The Frog Prince" — and the AI handles everything else automatically: expands your idea into a full story, extracts character descriptions and generates reference images, splits the story into scenes and writes detailed cinematic prompts for each one (camera work, lighting, color grading), generates AI video for every scene, writes narration and produces TTS voiceover, generates word-level synchronized subtitles, and concatenates everything into a single finished video. Ten steps, fully automated.

**Manuscript Video** — Perfect for explainers and educational content. Paste in a long article or script, and the system auto-splits it by speech duration (~4 characters per second), generates an AI video for each segment, then overlays a unified TTS narration and subtitle track across the full timeline. Paste a blog post in, get a narrated video out.

## Why It's Completely Free

The core reason: Agnes AI offers a set of free AI model APIs.

| Capability | Model | Cost |
|-----------|-------|------|
| Script Generation | agnes-2.0-flash | Free |
| Image Generation | agnes-image-2.1-flash | Free |
| Video Generation | agnes-video-v2.0 | Free |
| Voiceover | Microsoft Edge TTS | Free |

The first three come from Agnes AI's free-tier models. The voiceover uses Microsoft Edge TTS, which needs no API key at all. Combine all four and you get an end-to-end video creation pipeline that costs nothing.

In my testing, the model quality is genuinely decent. The video generation produces detailed frames, the LLM writes surprisingly good shot-by-shot scripts, and Edge TTS's Chinese voices are more natural than I expected. It's not going to beat top-tier paid tools, but considering the price tag is literally zero, the value is absurd.

## Narration and Subtitles: Better Than Expected

The narration deserves a mention on its own. Edge TTS provides 4 Chinese voice roles: a gentle female voice (Xiaoxiao), a steady male voice (Yunyang), a lively female voice (Xiaoyi), and a young male voice (Yunxi). Speech rate is adjustable from -30% to +30%.

The subtitles aren't just the narration text chopped into rough chunks and slapped on screen. They use Edge TTS's SubMaker to get **word-level timestamps**, producing a new subtitle every 2-3 characters with precise audio sync. Long subtitles auto-wrap into two lines, and the break point is chosen at punctuation boundaries — so you never get a single orphan character pushed to a second line.

Subtitle styling is fully customizable: font, color, size, position (top or bottom), stroke width, and semi-transparent background.

## How Scenes Connect

The trickiest part of multi-scene video is transitions. Split a story into 5 scenes and if each one is independent, the final cut feels jumpy.

This project offers three chaining modes:

**Keyframes mode (recommended)** — Each scene gets a specified first frame and last frame. The last frame of scene N automatically becomes the first frame of scene N+1, creating smooth visual continuity between adjacent scenes.

**Transition frame mode (ti2vid)** — The last frame of the previous scene is extracted, processed through img2img to create a transition image, and used as the starting frame for the next scene. Also achieves continuity, but with less precise control.

**Independent mode** — All scenes are generated independently from the same reference image. Good for content that doesn't need strong visual continuity, like explainer videos.

## Under the Hood

The backend is Python + FastAPI. The frontend is a single-file HTML SPA with Tailwind CSS and zero build steps. The whole project is about 5,000 lines of Python and 1,500 lines of frontend code, cleanly structured.

A few design decisions I'm particularly happy with:

**Checkpoint resume** — After every pipeline step, state is atomically written to `task_state.json` (write to a temp file, then `os.replace` to prevent corruption if the process gets killed). Restart the server after an interruption, hit "Resume" on the incomplete task, and it picks up where it left off — no duplicate API calls.

**Unified audio track** — Instead of generating audio per scene and concatenating (which accumulates padding gaps), all scene videos are concatenated first, then a single narration + subtitle track is laid across the full timeline. If the narration runs longer than the video, the last frame is automatically frozen to extend the duration.

**CJK font fallback** — When rendering subtitles, the system detects whether the chosen font supports CJK characters. If not (say, Arial), it automatically falls back to a built-in Chinese font, so you never see boxes instead of characters.

**WebSocket real-time progress** — The frontend shows live status for every step during generation, so you're not just staring at a blank screen.

## How to Use It

Three steps:

```bash
# 1. Clone and launch
git clone https://github.com/easyeye163/agnes-video-generator.git
cd agnes-video-generator
./start.sh

# 2. Get a free API key
# Visit https://platform.agnes-ai.com to sign up

# 3. Open http://localhost:8765, enter your API key, pick a mode, write your idea, hit generate
```

`start.sh` automatically creates a virtual environment, installs dependencies, and starts the server. Requirements: just Python 3.10+ and ffmpeg.

If you use an AI coding assistant (Cursor, Claude, etc.), the project includes a dedicated `AGENTS.md` — just tell your agent to read it and it'll handle deployment and verification automatically.

## Known Limitations

Honesty time — the project is still early stage, and some rough edges remain:

Network instability can cause retry failures on certain steps. Long single-scene videos (over 20 seconds) take a while to generate, so patience is required. If custom end-frame count doesn't match scene count, behavior is undefined. Running multiple video generation tasks concurrently may cause resource contention.

But the core generation pipeline is solid. I haven't run into any real issues in my own use.
