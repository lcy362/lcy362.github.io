知乎是个什么样的网站，大家都比较了解。今天我们换个角度——分享一个让"上班用知乎"这件事变得更安全、更高效的小工具。

<!-- more -->

## 摸鱼经济学：为什么是知乎？

之前我翻了一下自己知乎账号的后台数据，发现一个很有意思的现象：**PC 端的流量居然占了 40% 以上**。在移动互联网时代，这个比例高得不太正常。

后来从一些其他渠道也了解到，知乎周末和节假日的流量明显不如工作日。这说明什么呢？

**上班刷知乎的你，不是一个人。**

对相当一部分人来说，知乎主要的使用场景就是——上班摸鱼。而且知乎这个网站确实天然适合摸鱼：

- **以文字内容为主**，不像短视频那样有声音、耗流量
- **有大量专业性内容**，被老板路过看到屏幕时，可以说"我在查技术资料"
- **文章篇幅适中**，一条时间线看几分钟，心理负担小

## 知乎摸鱼的三个痛点

但知乎 PC 端有些设计，对摸鱼党不太友好：

**1. 图片太大**

知乎文章的配图经常会占满大半个屏幕。不管文章本身多正经，一张巨大的图片出现在屏幕上，旁边同事一瞥就能看到——这时候你说"我在看技术文章"就显得很没说服力。

**2. 标题浮窗抢眼球**

浏览知乎问题时，页面上方会有一个非常显眼的标题浮窗。它不仅占了一行空间，而且白底黑字特别突出，路人一眼就知道你在看知乎。

**3. Logo 高调**

知乎的 logo 统一放在页面左上角，任何时候截图或别人瞄一眼屏幕，品牌辨识度拉满。

## 脚本解决方案

我写了一个油猴脚本，针对性解决了这三个问题：

- **限制图片尺寸**：最大宽度设为 300px，所有文章配图变成小图，不抢眼
- **隐藏标题浮窗**：问题页面的标题浮窗直接移除
- **去掉知乎 Logo**：页面左上角的知乎 logo 一并隐藏

这样一来，知乎页面看起来就像一个普通的文字阅读器——干净、低调，非常适合在办公室环境中使用。

## 安装和使用

脚本已发布在 GreasyFork：

**[安装地址](https://greasyfork.org/zh-CN/scripts/483047-%E6%91%B8%E9%B1%BC%E5%8A%A9%E6%89%8B-%E7%9F%A5%E4%B9%8E)**

安装前提是浏览器中已安装 Tampermonkey（油猴）扩展。安装脚本后自动生效，无需配置。

## 技术实现

脚本的实现其实非常简单，核心就是通过 `GM_addStyle` 注入自定义 CSS：

```javascript
// 限制图片最大宽度
GM_addStyle('.RichContent img { max-width: 300px !important; }');

// 隐藏标题浮窗
GM_addStyle('.QuestionHeader { display: none !important; }');

// 去除 Logo
GM_addStyle('.AppHeader-logo { display: none !important; }');
```

本质上就是几行 CSS——但效果出奇的好。油猴脚本的妙处也正在于此：很多时候你不用写复杂的逻辑，只靠注入 CSS 就能显著改变网页的视觉体验。
